# Посты для Threads без признаков ИИ

Прочитать перед работой:
- `references/account.md`: кто пишет, разрешённые факты, рубрики, примеры голоса;
- `references/ai-signs-ru.md`: признаки сгенерированного текста и чем их заменять.

## Порядок работы

1. **Контекст.** Если есть доступ к API (`python3 ops/threads/api.py recent 10`), посмотреть последние посты и их просмотры: не повторять тему и рубрику, заметить, что набрало больше просмотров и ответов. Без доступа спросить пользователя или взять рубрику, которой давно не было.
2. **Тема.** Одна мысль на пост. Выбрать рубрику из `account.md` и конкретную нишу (потолки, кухни, вывески, кузов…). Пост для всех ниш сразу звучит ни для кого.
3. **Черновик.** Написать так, как владелец мастерской объяснял бы знакомому: от первого лица, конкретными словами, короткими предложениями разной длины. Первая строка сама по себе интересна, без разгона. 150–350 знаков обычно лучше всего, предел 500.
4. **Проверка по признакам.** Пройти чек-лист ниже. Каждое совпадение переписать, а не заменить синонимом.
5. **Длина и разметка.** `python3 ops/threads/api.py check FILE`, если доступен; иначе посчитать самому, эмодзи считать за 4 знака.
6. **Выдать.** Пост целиком, в каком он будет опубликован, рубрика и одна строка «почему эта тема сейчас». По желанию второй вариант первой строки. Без пояснений, что «пост написан живым языком».

## Чек-лист перед выдачей

- [ ] Все факты есть в `account.md` или пришли от пользователя. Нет выдуманных клиентов, цифр, отзывов, лет опыта.
- [ ] Нет «ключевой роли», «важно отметить», «стоит учесть», «уникальный», «качественный», «эффективное решение», «индивидуальный подход», «вывести на новый уровень».
- [ ] Ни один предмет не «обеспечивает», «подчёркивает», «демонстрирует», «отражает». Действует человек.
- [ ] Нет «не только…, но и…», «это не про X, это про Y», «X? Нет. Y».
- [ ] Нет тройных перечислений, «от … до …», синонимической карусели.
- [ ] Не больше одного деепричастия, нет канцелярита («является», «данный», «осуществлять», «в рамках»).
- [ ] Начало без «Друзья», «Давайте разберёмся», «Представьте», «В современном мире». Конец без морали, итога и «А вы как думаете?». Если вопрос, то конкретный.
- [ ] Нет длинных тире, `**`, `#`, списков с жирными заголовками, эмодзи-маркеров, хештегов. Эмодзи максимум одно и только если без него хуже.
- [ ] Оффер не чаще раза в неделю и только в рубрике «Оффер» или в последней строке примера.
- [ ] Прочитать вслух: звучит как человек в переписке, а не как пресс-релиз.

Оценить по stop-slop (если доступен): прямота, ритм, доверие к читателю, живость, плотность, каждое от 1 до 10. Ниже 35 из 50 переписать.

## Ответы людям

Для ответа под постом «нужен сайт / кто сделает сайт»: 2–3 предложения, один пример по нише человека из `account.md`, предложение бесплатного первого экрана, контакт. Без приветствия-простыни, без «Конечно!», без цены, пока не спросили. Если человек ищет то, чего TURCH не делает (CRM, Битрикс, интернет-магазин на тысячи товаров, мобильное приложение), честно пропустить.

## Публикация

Навык только пишет. Публикует пользователь или задача по расписанию после явного «ок» пользователя: `python3 ops/threads/api.py post FILE`.
