# Задача: поиск людей, которым нужен сайт (каждые 3 часа)

Ты работаешь по расписанию, пользователя рядом нет. Итог работы — последнее сообщение: оно приходит пользователю уведомлением на телефон. Никому не пиши и ничего не публикуй сам: ответы людям отправляет пользователь.

1. Подготовка:
   - репозиторий: если `~/turch-portfolio` нет, `git clone -q --depth 1 https://github.com/Olpest22/turch-portfolio ~/turch-portfolio`, иначе `git -C ~/turch-portfolio pull -q`. Дальше работай в нём;
   - программа `th`: проверь `th version`. Если её нет, собери шаг из раздела «Окружение» в `ops/threads/README.md`.
2. Сбор: `python3 ops/threads/hunt.py --minutes 6 --hours 3.5 > /tmp/candidates.jsonl`. В stderr будет, сколько постов прочитано.
3. Отбор. Прочитай каждого кандидата и оставь только тех, где человек сам ищет, кто сделает ему сайт, лендинг или переделает старый: для своего дела, услуги, мастерской, магазина, экспертной практики. Отбрасывай:
   - веб-дизайнеров и студии, которые рекламируют себя, «ветки саморекламы»;
   - учеников и новичков, которые спрашивают, как найти клиентов;
   - вакансии в штат;
   - то, что TURCH не делает: CRM, Битрикс, интернет-магазины на сотни товаров, мобильные приложения, сложные сервисы;
   - шутки, жалобы на сайты, новости.
   Если страна не Россия (₸, Казахстан, Беларусь), оставь, но отметь.
4. Для каждого отобранного напиши ответ по навыку `.claude/skills/threads-posts` (прочитай `SKILL.md`, `references/account.md` и `references/ai-signs-ru.md`, раздел «Ответы людям»). Пример бери по нише человека; если ниши нет в портфолио, дай главную ссылку портфолио.
5. Последнее сообщение, строго в таком виде, без вступлений:
   - если подходящих нет: `Новых запросов нет. Прочитано постов: N.`
   - если есть:
     ```
     Нашёл запросов: K (прочитано постов: N)

     1. @username, 25 мин назад, ответов под постом: 3
     Ищет: одна строка, что именно нужно.
     https://www.threads.com/@username/post/…
     Ответ:
     текст ответа
     ```
   Сначала самые свежие и с наименьшим числом ответов: туда ещё не набежали другие дизайнеры.
