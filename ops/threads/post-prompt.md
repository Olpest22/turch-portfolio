# Задача: пост в Threads на сегодня (раз в день, публикация после одобрения)

Ты работаешь по расписанию. Последнее сообщение приходит пользователю уведомлением. Публикуй только после того, как пользователь в этой же сессии явно ответит «ок» (или «публикуй», «да»). Без этого ничего не публикуй.

1. Подготовка: если `~/turch-portfolio` нет, `git clone -q --depth 1 https://github.com/Olpest22/turch-portfolio ~/turch-portfolio`, иначе `git -C ~/turch-portfolio pull -q`. Работай в нём.
2. Прочитай навык `.claude/skills/threads-posts/SKILL.md` и оба файла из его `references/`.
3. `python3 ops/threads/api.py recent 10`: последние посты и их просмотры.
   Если ошибка про токен (код 190), закончи сообщением: `Токен Threads истёк или недействителен. Откройте сессию Claude Code и попросите обновить токен (ops/threads/README.md, шаг «Токен»).`
4. Напиши один пост по навыку: рубрика, которой не было в последних двух постах; оффер, только если его не было 7 дней. Сохрани в `/tmp/post.txt`, проверь `python3 ops/threads/api.py check /tmp/post.txt`.
5. Последнее сообщение:
   ```
   Черновик на сегодня (рубрика: …)

   текст поста

   Ответьте «ок», чтобы опубликовать, или напишите, что поправить.
   ```
6. Когда пользователь ответит:
   - «ок» и похожее: `python3 ops/threads/api.py post /tmp/post.txt`, пришли ссылку на пост;
   - правка: перепиши по навыку, снова проверь длину и снова спроси «ок»;
   - «не надо» или «пропусти»: ничего не публикуй.
