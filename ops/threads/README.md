# Threads: автопостинг и поиск клиентов

Что работает:

| Что | Когда | Что делает |
|---|---|---|
| Черновик поста | каждый день | Claude пишет пост по навыку `.claude/skills/threads-posts` и присылает уведомление. Вы отвечаете «ок», пост публикуется через API Threads. |
| Поиск клиентов | каждые 3 часа, 9:00–21:00 МСК | Собирает свежие публичные посты, оставляет те, где человек ищет, кто сделает сайт, и присылает список со ссылками и готовым ответом. Отвечаете вы сами. |

Файлы:
- `api.py` — публикация и статистика через официальный API Threads;
- `hunt.py` — сбор свежих постов программой `th`;
- `post-prompt.md`, `hunt-prompt.md` — инструкции для задач по расписанию: их можно править здесь, не трогая сами задачи;
- `../../.claude/skills/threads-posts/` — навык письма: факты об аккаунте, рубрики, признаки сгенерированного текста.

## Настройка (один раз)

### 1. Аккаунт Threads
Создайте аккаунт в приложении Threads (можно без Instagram). Имя, например, `turch.sites`. В описании одна строка о том, что вы делаете, и ссылка на портфолио: https://olpest22.github.io/turch-portfolio/
Аккаунт должен быть публичным.

### 2. Приложение Meta
1. Зайдите на https://developers.facebook.com/apps и войдите (аккаунт разработчика Meta, подтверждение по телефону).
2. «Создать приложение» → сценарий **Access the Threads API** («Доступ к Threads API») → название, например `turch-posting` → создать. Подтверждение компании не нужно.
3. В приложении: «Сценарии использования» → Threads API → «Настроить» → «Разрешения». Добавьте `threads_basic`, `threads_content_publish`, `threads_manage_insights`, `threads_read_replies`.
4. Там же «Настройки»: в поля Redirect, Deauthorize и Data deletion вставьте `https://olpest22.github.io/turch-portfolio/` и сохраните.
5. «Роли приложения» → «Роли» → «Добавить людей» → роль **Threads Tester** → ваш ник в Threads.
6. В Threads: «Настройки» → «Аккаунт» → «Разрешения для веб-сайтов» → «Приглашения» → принять (или https://www.threads.com/settings/account).

Проверка приложением Meta не нужна: тестировщик может публиковать в свой аккаунт.

### 3. Токен
1. В приложении: Threads API → «Настройки» → блок **User Token Generator** → у вашего аккаунта «Сгенерировать токен» → войти и разрешить.
   Если такого блока нет: Graph API Explorer (https://developers.facebook.com/tools/explorer), выберите своё приложение и Threads, отметьте разрешения из шага 2.3, «Generate Threads Access Token».
2. Токен из Explorer живёт час. Его нужно обменять на 60-дневный: откройте в своём браузере, подставив значения:
   `https://graph.threads.net/access_token?grant_type=th_exchange_token&client_secret=СЕКРЕТ_ПРИЛОЖЕНИЯ&access_token=ТОКЕН`
   Секрет: «Настройки» → «Основное» → **Threads app secret** (не Facebook). В ответе будет новый `access_token`.
3. Скажите Claude: «токен готов». Откроется защищённая форма, вставьте токен туда. **Не присылайте токен в чат.** Он сохранится в окружении Claude и будет подставляться в запросы к graph.threads.com, в репозиторий он не попадает.

Токен действует 60 дней. За неделю до конца придёт напоминание: сгенерируйте новый тем же способом и сохраните через форму.

## Окружение

Программу `th` задача поиска ставит сама при первом запуске в новом контейнере: `bash ops/threads/install-th.sh`. Скрипт собирает её из исходников на проверенной версии (коммит зафиксирован в скрипте). На своём компьютере нужен Go: https://go.dev/dl

## Ограничения

- Поиск читает публичную ленту без входа в аккаунт. Threads может её изменить, тогда поиск начнёт возвращать ноль, и `th` придётся обновить. Официальный поиск API ищет по чужим постам только после проверки приложения Meta.
- Каждая задача по расписанию расходует лимиты вашей подписки Claude: это 5 поисков и 1 пост в день.
- API Threads: до 250 постов в сутки, 500 знаков на пост.
